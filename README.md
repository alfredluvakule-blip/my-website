# my website

A hand-built, animated personal website — no frameworks, no build step, just one HTML file.

## What's inside

- **Animated landing page** — staggered hero reveal, ambient drifting-motes canvas, scroll-triggered section reveals, and hover micro-interactions.
- **Focus app** — a tiny pomodoro timer with an animated progress ring, built right into the page.
- **Light & dark themes** — follows your system preference, with a manual toggle.
- **Accessible** — respects `prefers-reduced-motion`, keyboard-focus states, ARIA labels.

## Publishing

The site deploys to GitHub Pages automatically via `.github/workflows/deploy.yml` on every push to `main`. Once merged, it will be live at:

https://alfredluvakule-blip.github.io/my-website/

(If the first deploy fails, enable Pages once in **Settings → Pages → Source: GitHub Actions**, then re-run the workflow.)

## Local preview

Just open `index.html` in a browser — there's nothing to install.
